API de Aposentabilidade

API REST em Flask que aplica a regra de elegibilidade a aposentadoria, com teste automatizado e CI/CD.

  • Quatro camadas separadas: a regra de negócio é função pura, sem Flask nem Pandas, e por isso testável sozinha.
  • Endpoints com validação de entrada: GET /api/servidores com filtros e paginação, GET /api/servidores/<id>, GET /api/resumo e POST /api/avaliar.
  • Quando a pessoa não é elegível, a resposta traz os motivos, um por critério que falhou, em vez de um "não" seco.
  • 44 testes com pytest, 99% de cobertura, com atenção aos limites da regra: exatamente 60 anos não passa.
  • CI roda a suíte em quatro versões do Python e o flake8; CD publica a imagem Docker no Container Registry a partir de uma tag.

Contribuições no Orion Agent

Patches no provider de modelos de um agente multi-agente open source, além da instalação local completa.

  • Patch no provider Anthropic para ler o endpoint a partir de anthropic_base_url (settings ou variável de ambiente).

  • Instalação self-hosted do projeto (Python 3.12 via uv, API REST e WebSocket, interface web) com credencial guardada no Keychain do macOS.
